# Tiff Screen Assistant v5 (Android APK)

Personal AI screen companion with **Personal Telegram App Auto-Driver**, **Two-Way Telegram Bot Bridge**, **Tiff's Soul**, **Female Voices**, **Persistent Memory**, **Direct App Intents**, and a **GitHub Actions cloud APK builder**.

## How to Build Your Downloadable APK in GitHub
1. Extract this zip and upload all files (including `.github/workflows/build-apk.yml`) to your GitHub repository.
2. Open the **Actions** tab and run **Build Tiff Android APK**.
3. Download **Tiff-Screen-Assistant-v5-APK** from the workflow **Artifacts** section.
